# Wi-Fi 撮影

Windows PCを受け取り先にする家再現用のローカルサイト。スマホから選んだ写真・動画の一括送信と、カメラで撮ったPNGの連続送信に対応する。クラウドへの転送、アカウント、撮影時間の上限はない。

## 接続と保存

1. PCで [Start-WiFi-Capture.cmd](../Start-WiFi-Capture.cmd) を開く。初回は学習に必要なツールを取得する。スマホを同じルーターのWi-Fiにつなぎ、PCのページに出るQRコードを読み取る。PCが有線接続でも、同じルーターにつながっていれば使える。
2. 既存の写真や動画は「ファイル送信」で複数選んで「PCに送信」を押す。スマホのブラウザーから渡されたファイルをそのまま保存する。撮影と同時に使うときは、先に撮影ページ（HTTPS）を開く。「PCに送信」を押したあと、同じページの「カメラ撮影」に切り替えられる。
3. PCの `input` に、撮影・送信ごとのフォルダができる。別の保存先を使いたい場合は、保存先にしたいフォルダを起動用CMDにドラッグする。サーバーが動いている間はPCのページから停止してから起動し直す。

## カメラで撮る

- iPhoneのSafariはHTTPSでカメラを使う。初回は「iPhoneの初回設定」を開き、撮影用プロファイルの手順を済ませてから「撮影ページを開く」を押す。写真・動画を選んで送るだけならこの手順は不要。
- 「カメラを開く」を押し、Safariでカメラを許可すると映像が出る。「撮影開始」で連続撮影が始まり、赤い「撮影停止」で終わる。映像が出たら「写真を撮る」で、連続撮影の前でも途中でも写真を保存できる。カメラ映像は縦持ちで3:4、横持ちで4:3。PNGも画面と同じ範囲を保存する。
- 撮ったPNGから順にPCへ送る。前の写真を送信中でも、送信待ちに空きがあれば次の写真を撮れる。連続撮影では、Wi-Fiの送信が追いつかないときに自動のコマを間引き、写真用の空きを確保する。撮影画面に保存枚数と送信待ちが出る。カメラを閉じても、同じページを開いたままなら送信は続く。
- 小さな「画質・fps」をタップすると長辺解像度とfpsを変更できる。設定の「保存サイズ」が実際に出力する寸法。端末の映像が上限になり、設定には保存枚数、送信待ち、実測fpsも出る。「カメラを閉じる」かブラウザーの戻る操作で終了する。
- 「方角・傾きの記録を許可」を押すと、端末から得られる姿勢をコマと同じ順番で `frames.jsonl` に保存する。方角を取得できないコマは値が空になる。ファイルには撮影時刻・経過ミリ秒・画像寸法・前後左右の傾きと画面の向きを記録する。

## 学習に使う

1. ファイルの送信完了を待つ。カメラで撮影した場合は、連続撮影を止めて送信待ちが0枚になったらカメラを閉じる。
2. 保存状況の下にある「このフォルダで学習開始」を押す。対象は同じ送信・撮影フォルダの素材。学習の設定は長辺1,920 px、動画抽出5 fps、登録画像1枚あたり平均20ステップ、最大400万点。
3. PCで起動したウィンドウを開いたままにする。スマホ画面に学習の状態が表示される。結果の `room.ply` と `run.log` はPCの `runs` に、起動時のログは素材フォルダに保存される。

設定を選ぶ場合や、同じ部屋の複数回分をまとめる場合は、PCで [Train-Room.cmd](../Train-Room.cmd) を開く。1回分だけ選ぶ場合は、保存状況に表示されたフォルダをCMDにドラッグする。各フォルダ内でPNGと `frames.jsonl` を一緒に置き、画像のファイル名を保つ。

COLMAPは `frames.jsonl` の順番で近くのコマを、姿勢が取れていれば同じ撮影内で似た向きの離れたコマも照合候補にする。別の撮影や既存の写真との照合には代表コマを使う。室内のカメラ位置と向きは共通して写った特徴から求める。`session.json` は撮影設定の控え。JPEGも学習用の画像として使える。
